# Soluway — Sitio Web Institucional

Sitio estático de [Soluway](http://soluway.com.ar), empresa de AI y automatización para pymes y negocios locales.

## Stack

- HTML + CSS escrito a mano (sin frameworks ni build step)
- Google Fonts (Space Grotesk, Inter, IBM Plex Mono)
- Formulario de contacto via [Formspree](https://formspree.io)

## Estructura

```
├── index.html       # Sitio completo (single-page)
├── PRODUCT.md       # Verdad de producto y compromisos de marca
├── DESIGN.md        # Sistema de diseño derivado del build
├── assets/          # Logo, isologo y favicon
└── CNAME            # Dominio personalizado para GitHub Pages
```

## Secciones

- Hero
- Posibilidades (qué se puede automatizar)
- Caso real (antes / después, anonimizado)
- Herramientas construidas
- Cómo trabajamos
- Contacto (formulario → soluway.group@gmail.com)
- Legales (acordeones en el footer)

## Deploy

El sitio está publicado con **GitHub Pages** en:
- https://mattiasledesma.github.io/Soluway/
- http://soluway.com.ar (dominio personalizado)

Para actualizar: hacer push a `main` y GitHub Pages publica automáticamente en ~1 minuto.
